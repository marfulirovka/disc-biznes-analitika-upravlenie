# Бизнес-аналитика в управлении организацией

Материалы курса для группы. Лекции, семинары и вопросы к итоговому контролю.

## Структура

- `literature.md` — список литературы с рекомендациями
- `lectures/` — конспекты и презентации по темам
- `seminars/` — рабочая тетрадь, задание и маршрутный лист по каждому семинару
- `control/` — вопросы к зачёту/экзамену и примеры практических заданий

## Как пользоваться

Откройте нужную тему в `lectures/` или `seminars/` — там конспект/презентация или рабочая тетрадь с заданием.
Перед зачётом/экзаменом — `control/`.
