# Бизнес-аналитика в управлении организацией

Материалы курса для группы БИЗ-Б-04-Д-2023-1. Лекции, семинары и вопросы к итоговому контролю.

Направление 38.03.05 «Бизнес-информатика», профиль «Бизнес-аналитика», 4 курс, осенний семестр 2026/2027.

## Структура

- `plan-zanyatiy.md` — план занятий: распределение нагрузки, тематика лекций и практик, график выдачи/сдачи заданий по блокам, критерии аттестации, литература
- `lectures/` — конспекты по темам (лекции 1–4 из 12 готовы; презентации пока только в формате pptx, не в этом репозитории)
- `seminars/block-01/` — раздаточные материалы блока 1 (занятия 1–5: выбор организации-кейса, паспорт кейса, аналитический вопрос, карта стейкхолдеров, защита)
- `seminars/block-02/` — раздаточные материалы блока 2 (занятия 6–10: цепочка ценности, дерево целей, карта контуров, матрица решений, выбор объекта проекта)
- `literature.md` — список литературы (в работе)
- `control/` — вопросы к зачёту (в работе)

## Как пользоваться

Откройте нужную тему в `lectures/` — там развёрнутый конспект занятия.
В `seminars/block-NN/` — раздаточные материалы к текущему блоку практических занятий; рабочая тетрадь и маршрутный лист по каждому отдельному занятию блока будут добавлены позже.

## Итоговый контроль по курсу

**Зачёт** (осенний семестр — дифференцированный зачёт, защита аналитического проекта по организации-кейсу).
