# Р6. Форма аналитического вопроса

Дисциплина «Бизнес-аналитика в управлении организацией»

Направление 38.03.05 «Бизнес-информатика», профиль «Бизнес-аналитика», 4 курс, осенний семестр. Группа БИЗ-Б-04-Д-2023-1 (7 человек)

Блок 1. Практические занятия 1–5. Раздаточный материал

**Форма.** У кого — что происходит — насколько это отличается от нормы — с какими последствиями.

Пример корректной формулировки: «В магазинах сети доля позиций с нулевым остатком в категории бакалея составляет 7 % при внутреннем нормативе 2 %; по оценке коммерческой службы это соответствует потере около 5 миллионов рублей выручки в год».

## Бланк

| Элемент | Ваша формулировка |
|---|---|
| У кого (адресат, подразделение, роль) | |
| Что происходит (измеряемое явление) | |
| Насколько отличается от нормы (число и норматив) | |
| Источник числа и период | |
| С какими последствиями (для кого и в чём измеряется) | |
| Итоговая формулировка одним предложением | |

## Критерии проверки

- Все четыре элемента присутствуют явно.
- Есть число и указан источник; если данных нет — записано, каким измерением число будет получено.
- Нет предрешённого решения и названия конкретного продукта.
- Нет виноватого: формулировка описывает механизм, а не человека.
- Формулировку можно проверить: другой человек, получив те же данные, придёт к тому же выводу.

> Готовится вторая редакция этого раздатка, различающая понятия «проблема» и «аналитический вопрос» — сейчас в разработке, не публикуется до согласования.
