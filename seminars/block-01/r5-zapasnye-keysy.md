# Р5. Запасные организации-кейсы

Дисциплина «Бизнес-аналитика в управлении организацией»

Направление 38.03.05 «Бизнес-информатика», профиль «Бизнес-аналитика», 4 курс, осенний семестр. Группа БИЗ-Б-04-Д-2023-1 (7 человек)

Блок 1. Практические занятия 1–5. Раздаточный материал

Выдаются студентам, чей вариант не прошёл чек-лист Р3. Все варианты допускают работу на открытых или внутренних доступных данных.

| Кейс | Решение для анализа | Источники данных |
|---|---|---|
| Приёмная кампания факультета | Распределение усилий по каналам привлечения абитуриентов | Открытая статистика приёма, данные факультета |
| Библиотека университета | Комплектование фонда: что закупать и в каком количестве | Статистика выдачи, каталог |
| Учебный отдел | Формирование расписания: распределение аудиторного фонда | Расписание, данные о загрузке аудиторий |
| Закупки лаборатории | Выбор конфигурации оборудования при ограниченном бюджете | Спецификации, коммерческие предложения |
| Публичная торговая сеть | Открытие или закрытие точки в регионе | Годовая отчётность, презентации для инвесторов |
| Публичный ИТ-интегратор | Приоритизация направлений услуг | Годовая отчётность, отраслевые обзоры |

Для двух последних вариантов обязательна оговорка в отчёте: работа ведётся на открытых данных, доступа к внутренней информации нет, часть выводов носит гипотетический характер.
